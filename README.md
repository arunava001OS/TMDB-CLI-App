## Reference - https://roadmap.sh/projects/tmdb-cli
## Usage

### 1. Clone the repository to your machine
### 2. run "npm i"
### 3. To use the CLI from anywhere run "npm install -g"
### 4. In any cli type "tmdb-movie-tool -t <type> -l <language> -p<page>"
### 5. To review options type "tmdb-movie-tool --help"
